# B站兴趣调谐器 · Bili Interest Tuner

> ✦ Blades Original ✦ — 原创作品，转载 / 衍生请注明出处

<!-- Watermark: Blades -->

一个从浏览器历史记录中自动提取关键词、分析用户兴趣画像，并应用到 B 站推荐流的浏览器扩展。
让推荐算法**只推你想看的，屏蔽你不想看的**——把推荐权从算法手里拿回来。

<!-- Watermark: Blades -->

## 功能总览

| 模块 | 能力 | 说明 |
|---|---|---|
| 📊 处理流程 | 分析浏览器历史 | 提取关键词、词频统计、按频率排序 |
| 🔢 关键词 | 词频列表 | 显示每个关键词出现次数，可勾选 |
| 🎯 兴趣画像 | AI 分类 | 区分有意义词 / 无意义词，生成兴趣画像 |
| 🧭 分区过滤 | 自动点"不感兴趣" | 仅对非勾选分区的视频执行，需用户同意 |
| 🚀 应用到B站 | 静默搜索投喂 | 用 fetch 静默发送搜索请求，影响推荐算法 |
| 📝 配置 | 自定义 & 已选 | 管理自定义关键词和已选兴趣 |

## 核心原理

### 1. 历史关键词提取

- 调用 `chrome.history` API 获取浏览历史
- 提取每个页面的标题和 URL，分词后统计词频
- 按频率排序展示，用户可勾选感兴趣的关键词

### 2. 分区识别与"不感兴趣"自动点击

content.js 注入 B 站页面后：

- **严格只读分区选择器**：`.tname` / `.zone-name` / `.bili-video-card__info--channel` 等，排除普通标签误判
- 仅当视频的分区**不在用户勾选列表**中时，才模拟点击"不感兴趣"
- 点击流程：
  1. hover 视频卡片（触发"更多"按钮显示）
  2. 点击"更多"（三个点）
  3. 在弹出菜单中找"不感兴趣"并点击
- 每一步都有 `[BIT]` 前缀的 console 日志，方便调试
- 视觉反馈：成功点击 → 绿框 + 绿色勾角标；未找到按钮 → 橙色角标

<!-- Watermark: Blades -->

### 3. 静默搜索投喂推荐算法

- 对勾选的关键词，用 `fetch` 静默发送 B 站搜索请求
- 不弹出新标签页，用户无感知
- Top 10 关键词 × 每词 3 次请求，提升推荐算法对用户兴趣的学习

<!-- Watermark: Blades -->

### 4. 四宫格布局

插件 UI 采用四宫格设计：

| 位置 | 模块 | 可折叠 |
|---|---|---|
| 左上 | 处理流程 + 分析按钮 | ❌ 永远展开 |
| 右上 | 关键词 + 兴趣画像 | ❌ 永远展开 |
| 左下 | 分区过滤 + 应用按钮 | ✅ 默认收起 |
| 右下 | 配置（自定义 & 已选） | ✅ 默认收起 |

- 各模块内独立滚动，按钮固定在模块底部（独立于滚动）
- 折叠状态自动保存到 `chrome.storage.local`
- 两个下排模块都收起时，上排自动占满空间

<!-- Watermark: Blades -->

### 5. 内容识别扩展

除了视频标题，content.js 还识别：

- UP 主名称
- 标签 / 词条
- 视频简介
- 分区名

同时有黑名单机制，跳过"推荐观看"区域（`#reco_list` / `.related-video`），避免在推荐区误触发。

<!-- Watermark: Blades -->

### 6. 右侧悬浮提示栏

所有命中信息（想看关键词、兴趣命中、屏蔽词、分区不符、已点不感兴趣统计等）**不再以角标形式叠加在视频卡片上方**，而是统一显示在页面最右侧的一个**固定悬浮方框**中：

- 固定定位在页面右侧垂直居中，不遮挡任何视频内容
- 深色半透明背景（50% 透明度）+ 毛玻璃模糊
- 文字 80% 不透明度，清晰但不刺眼
- 分为「当前视频」和「推荐流统计」两个区块
- 200ms 防抖更新，支持无限滚动加载新卡片时实时刷新统计
- 卡片仅保留边框（绿框/橙框/红框），不再有任何遮挡性角标

## 使用方法

1. 在 `edge://extensions` 开启开发者模式 → 加载已解压的扩展（选 `bili-interest-tuner` 文件夹）
2. 点击插件图标 → 弹窗打开
3. 点"🔍 分析历史" → 提取关键词
4. 在关键词列表中勾选你感兴趣的内容
5. 点"💾 将上方勾选的内容保存到下方配置"
6. 展开左下"🧭 分区过滤" → 勾选你想保留的分区 → 勾选同意 → 点"🚀 应用到哔哩哔哩"
7. 打开 B 站首页，content.js 自动工作

> 调试：在 B 站页面按 F12 → Console 过滤 `[BIT]` 查看处理日志。
> 调试模式：控制台执行 `document.body.classList.add('bit-debug-show-hidden')` 可看到被隐藏的卡片。
